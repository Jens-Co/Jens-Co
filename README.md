## 💫 About Me

I'm Jens, a software developer passionate about building applications, backend systems and infrastructure.

Most of my work revolves around the Minecraft ecosystem, where I enjoy combining software engineering, networking and infrastructure to solve real-world problems.

- 🚀 Creator and lead developer of **MCCompanion**
- 🤝 Advisor for the **GeyserMC organization**
- 🛠️ Interested in application development, backend architecture and infrastructure
- 🌍 Building software for a global community

## 🚀 Featured Project

### MCCompanion

My main project and ongoing development focus.

MCCompanion is a cross-platform Minecraft companion application designed to make connecting to external Minecraft servers easier, particularly for Bedrock console players.

I work on the entire ecosystem, covering:

- Cross-platform application development
- Backend services and REST APIs
- Networking and UDP tunneling
- Server infrastructure and deployment
- Integrations with the Minecraft ecosystem

## 🤝 Community & Open Source

### [GeyserMC](https://github.com/GeyserMC)

I'm an advisor for the GeyserMC organization, supporting the team with technical experience, insights and guidance.

GeyserMC bridges the gap between Minecraft Java Edition and Bedrock Edition, allowing players from both platforms to play together.
